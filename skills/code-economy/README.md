# Code economy

**Problem:** agent-written code can accumulate abstractions for hypothetical futures.

**Why useful:** this skill supplies concrete deletion rules that keep a change understandable without weakening correctness.

**Scope:** implementation and refactoring. It does not replace project architecture, security, or test requirements.

**Use:** ask an agent to apply `code-economy` while implementing, or point its skill loader at this folder using a location supported by that harness. Follow the review-first process in [INSTALL.md](../../INSTALL.md).
