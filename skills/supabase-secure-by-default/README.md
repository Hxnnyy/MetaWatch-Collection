# Supabase secure by default

**Problem:** convenient Supabase defaults can be mistaken for an authorization design.

**Why useful:** this compact checklist keeps RLS, least privilege, constraints, storage, and negative tests visible.

**Scope:** posture and review prompts. It does not replace current official documentation, threat modelling, or project-specific policy design.

**Use:** invoke `supabase-secure-by-default` during Supabase design or review. Install only through a documented harness location using [INSTALL.md](../../INSTALL.md).
