# Frontend design

**Problem:** interface work can become visually generic, verbose, or insensitive to interaction and mobile composition.

**Why useful:** this skill joins composition, product language, responsive behaviour, motion, and final visual QA into one design discipline.

**Scope:** frontend design and refinement. It does not replace product requirements, accessibility testing, or an established design system.

**Ownership:** original MetaWatch-owned work authored by the user from their earlier design workflows and general influences. It is not presented as an exact or adapted copy of a third-party repository.

**Use:** install this complete skill bundle through the review-first process in [INSTALL.md](../../INSTALL.md).
