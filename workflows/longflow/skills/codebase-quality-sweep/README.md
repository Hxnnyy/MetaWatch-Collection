# Codebase quality sweep

**Problem:** broad hardening requests can become unprioritized lists with no closure path.

**Why useful:** this skill audits, triages, and turns findings into reviewable execution work.

**Scope:** systematic codebase quality work; it is not a substitute for a focused bug fix or security incident response.

**Use:** invoke deliberately for a repository-wide sweep. Follow [installation guidance](../../../../INSTALL.md).
