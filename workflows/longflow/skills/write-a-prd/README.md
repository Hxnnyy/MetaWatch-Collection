# Write a PRD

**Problem:** rough intent often lacks boundaries and mechanically verifiable completion criteria.

**Why useful:** this skill turns settled decisions into a delivery contract subordinate to the intent contract — promise trace, module map, frozen promise-level acceptance, and a subtraction pass that cuts unfunded scope.

**Scope:** PRD authoring after material product decisions are resolved; it does not implement the feature.

**Use:** invoke directly for a scoped PRD or through Longflow. Follow [installation guidance](../../../../INSTALL.md).
