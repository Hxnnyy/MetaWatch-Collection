# Issues execution

**Problem:** multi-issue delivery can drift, exhaust agents, or close without evidence.

**Why useful:** this skill governs bounded execution, rigour-classed verification, promise gates with walkthroughs and intent audits, and recovery.

**Scope:** implementing an approved issue tree; external writes remain subject to user authority and repository rules.

**Use:** run from Longflow after the ledger and ownership are settled. Follow [installation guidance](../../../../INSTALL.md).
