# Merge Train

**Problem:** large branches and pull requests can exceed the reliability of one-pass review.

**Why useful:** this skill audits, remediates, checkpoints, and prepares the parent change for manual merge review.

**Scope:** pre-merge readiness; it does not authorize merging, rewriting history, or bypassing branch policy.

**Use:** invoke `merge-train` on an existing branch or pull request after following [installation guidance](../../../../INSTALL.md).
